# Code of Conduct

## Our Pledge

We are committed to maintaining a respectful, inclusive, and constructive project environment. Everyone participating in this repository is expected to communicate professionally and act with empathy.

## Expected Behavior

- Use welcoming and respectful language
- Provide constructive feedback
- Stay focused on improving the project
- Respect differing viewpoints and experience levels
- Avoid sharing private information without permission

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory comments
- Personal attacks or insulting language
- Publishing private information without consent
- Spam, trolling, or intentionally disruptive behavior

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior does not align with this code of conduct.

## Reporting

Report concerns privately to the repository owner through GitHub or the contact channels listed in the portfolio.
